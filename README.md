# 🌌 Varoluşsal Kriz Generatorü v1.0

## Resmi Bilimsel Dokümantasyon

Bu proje, modern insanın en temel ihtiyacını karşılamak üzere geliştirilmiştir: **Yüksek kaliteli, kişiselleştirilmiş varoluşsal kriz üretimi.**

Geleneksel yöntemler (kitap okumak, gece 3'te tavana bakmak, eski sevgiliyi stalklamak) artık yetersiz kalmaktadır. Bu yazılım, kuantum belirsizlik prensibi ile birleşik Türk felsefe geleneğini harmanlayarak size saniyeler içinde profesyonel düzeyde bir kriz sunar.

### Özellikler
- %100 organik krizler
- Yapay zeka destekli (ama aslında random.choice)
- ISO 9001 uyumlu (hayır değil)
- Çalışma garantisi: Çalışmazsa daha da kriz yaşarsınız

### Kurulum
```bash
python kriz.py
```

Başka hiçbir şey gerekmez. Python 3+ yeterlidir. İnternet bile gerekmez. Evren zaten yeterince karmaşık.

### Kullanım
Programı çalıştırın. Ekrana bakın. Hayatınızı sorgulayın. İsteğe bağlı olarak çay için.

### Bilimsel Temel
Formülümüz şöyledir:

```
Kriz Seviyesi = (Rastgele Sayı × Yaş × Uykusuzluk) / Anlam
```

Anlam genellikle 0 olduğu için sonuç sonsuza gider. Bu da projenin başarısını kanıtlar.
